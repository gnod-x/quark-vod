首次连接 Telegram

  1. 在 Telegram 打开官方 @BotFather，发送 /newbot 创建机器人，复制它提供的 token。
  2. 打开你的机器人，先发送 /start。群组接收则先把机器人加入群组并发送一条消息。
  3. 个人 chat ID 可通过 Telegram 的 @userinfobot 查询；群组可通过 @RawDataBot 查看消息中的 chat.id，取得后可将查询机器人移出群组。不要向这些机器人提供 Bot token。
  4. 填写 token 和 chat ID，启用并保存，再发送测试。在 Telegram 接收端确认消息。
