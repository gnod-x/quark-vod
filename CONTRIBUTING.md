# Contributing

Use Python 3.11+ and work with synthetic fixtures.

```sh
python -m pip install -e '.[test]'
make test
python -m build
```

Preserve identity-before-quality matching, single-file transfer recovery,
bounded streaming resources, explicit credential sources and fail-closed
destructive maintenance. Add regressions for a reproduced failure before fixing
it. Tests must not contact real accounts, modify a running media library or call
an operator's AI service.

Search providers must include empty/partial/error cases, response limits and
configuration reload/cache separation tests. Keep server and client URLs
configurable. Do not commit cookies, tokens, signed media URLs, account databases,
user state or private deployment paths.

Document changed behavior and validate the installed wheel from a directory
outside the source tree. For container changes, test non-root/read-only startup
and the configured resource limits. Optional host integration tests are kept
separate from standalone tests.

Follow the existing source ownership and preserve notices for third-party code.
Do not vendor binaries without their corresponding redistribution materials.
