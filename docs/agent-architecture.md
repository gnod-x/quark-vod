# 点播架构与行为

2026-11-19 根据当前源码、真实接口和回归重写。运行版本、样本与验收范围统一见[影院续验](/home/dong/.agent-context/verification/cinema-continuation-2026-11-19.md)，测试和恢复见[验证流程](../../hometheater/docs/agent-verification.md)。

## 组件与接口

app/main.py 为 FastAPI 入口，server.py 协调播放；共享模块负责搜索、选择、保存、STRM 和维护。app/quark_vod → hometheater/scripts/quark_vod；七个宿主作业按反方向同步至 app/jobs。状态库为 hometheater/data/quark_plays.db，锁在 data/locks。容器使用 host 网络、只读 app 和 256 MiB 限额。

| 接口 | 行为和副作用 |
|---|---|
| /health、/stats | 本地健康与状态摘要 |
| GET /pending、/play | 先复用保存，再搜索/保存；可读并激活后重定向，否则 503 |
| HEAD /pending、/play | 不发起新保存，占位响应不证明可播 |
| /preheat | 后台准备、保存及置顶，与播放共享任务 |
| /media/{id}?v=…&skip=… | 从记录与版本取得 MP4，不接受任意上游地址 |
| /clean | 前缀清洗；支持 HEAD、单区间、后缀 Range 和 416 |
| /api/admin/search-debug | 候选打分和名称画质提示，不转存 |
| /capability、管理台 overview | 检查授权并创建、回读、删除唯一云探针 |
| selfheal、reset、cookie 管理 | 修改状态、入口或凭证，按具体行为验收 |

重定向适配器编码非 ASCII Location。启动登记 STRM、标记超时任务并检查云写能力；自愈首次延迟 120 秒，正常间隔 86400 秒，失败/暂缓一分钟重试。管理接口沿用当前内网使用范围，没有统一管理鉴权。

## 搜索与身份

panshare_matrix 的每关键词最多三页；每节点默认二十四个不同详情页、调用最多三十，去重后截取。下一页限制为同源搜索路径，响应体至多 2 MiB。每进程两个搜索槽、十二个 HTTP 槽，每节点三个详情线程；节点预算 22 秒，单 HTTP 最长七秒。预算控制后续调度，不是整轮硬墙钟。

search_report 最多四个查询变体，使用规范片名、季号、年份及原名。同一分享合并标题、来源和提取码。v3 缓存：完整非空三十分钟，partial/空四十五秒；内存最多 128 条，磁盘原子替换，命中仍过滤死链。

电影/剧集、年份、季集、动漫/真人、数字续作和特别篇先作身份门槛，再按匹配、4K 提示和相关度排序。后续季可使用该季年份；电影重拍版保持年份约束。没有季号仍须检查真实文件。门户原名来自 TMDB；播放/审计只从类型、标题和年份匹配、不经符号链接、至多 128 KiB 的作品 NFO 读取 originaltitle，不改变存储身份。

| 情况 | 播放协调器结果 |
|---|---|
| partial 且无合格候选 | search_incomplete |
| 完整搜索无合格候选 | source_unavailable，仅表示本次限定范围 |
| 搜索调用异常 | search_unavailable |
| 候选保存/确认均失败 | transfer_failed；partial 时保留搜索未完成说明 |

quality.py 的 verified 始终为 false。优先使用尺寸、明确低分辨率，再看 4K/2160/UHD 名称；3840 宽且高至少 1600 可含裁切宽银幕，2160×1080 不算 4K。目标文件低分辨率覆盖分享宣传，体积、HDR、DV 和 REMUX 不证明 4K。真实宽高和解码另验。

## 保存与播放

Work 为分类、保留年份的标题、季、集；电影 0/0，剧集季集为正，S00 暂不支持。旧无年份身份须有唯一映射证明。同身份共享 Future，同季跨进程锁；四工作线程、最多十六待处理任务。请求等待 180 秒到期不取消后台保存。

依次复用 done、恢复不明保存意图、尝试精确目标锁源、尝试最多八个搜索候选。锁源展示标题不重新打分，实际文件仍核对作品/季集/大小。只保存一个 fid 至确定性 vod_<hash> 目录；枚举最多 1200 条、六层，多个无法确认的电影正片拒绝按体积猜选。同身份版本先比较分辨率提示，再比较大小。

提交前持久化 save_target、save_started_at、task_id；结果不明先查原任务/目录，明确失败才重提。官方回读名称/大小后登记 done 和清理队列。读通道未就绪保留 done，不激活其他集。普通 inspect_share_video 默认六十秒预算，HTTP 404 不足以永久判死。

_finish 验证短 Range、前缀和入口激活；STRM 稳定为 /play，r 仅供身份反查，路径来自状态库。原子写保留权限/所有者，同内容不刷新。解析缓存三十秒、最多 64 身份，命中核对 done ID/路径，失败不缓存。

MP4/M4V/MOV/MP41 使用 /media：512 KiB 块、24 MiB 总缓存、五分钟 TTL/LRU、四个上游并发；客户端最多三十二连接、等待十秒，每次输出 128 KiB，断连释放槽。版本包含记录/路径/大小，旧版本拒绝复用。其他媒体走 QuarkTV，PNG 前缀走 /clean；没有 BMP 专用保证，不使用曾引发 OOM 的 interleaved_read=0。写入/删除和播放挂载属于同账号，不能由单次测速推断任意视频速度。

## 两层审计与持久轮转

根目录巡检按分类、标题、季、分享 SHA256 排序，data/source_lock_cursor.json 保存已完成尝试的位置；原始分享地址不落游标。可读只证明根目录存在，不改分集 checked_at。未知保留锁源；明确取消/过期或完整空分享才作废并寻找覆盖原目标集的替代源。单组异常计 unknown/errors，继续后续组；找不到替代源计 failed_dead，不声称全网无资源。

目标文件审计复用真实递归选择器，每组至多五百个目标。证据未满一天且状态有效时可复用；强制或过期核验先查最多两个旧锁源，再查最多六个新候选，分享去重。旧源不依赖当前搜索是否还能搜到。所有目标已有 4K 文件提示可跳过搜索；仅部分集找到不算完整覆盖。

完整枚举确认所选目标不存在时，仅将该集设 not_found/has_quark_source=0；枚举、网络或鉴权异常保留旧证据与时间。不修改本次未请求集，也不因缺一集全局拉黑分享。成功确认的文件各自更新提示；未知/异常计入未确认。已保存电影可返回 saved 与名称提示，此捷径不重新证明云文件可读。

文件审计按分类/标题/季排序，以 data/source_audit_cursor.json 轮转。两个游标互不替代：每次已发起尝试后推进，包括空结果、未知和异常；预算耗尽、尚未开始的项目不推进；到末尾回绕。游标经唯一临时文件、fsync 和原子替换，权限 0644。作业预算、互斥与运行版本见[影院架构](../../hometheater/docs/agent-architecture.md)。

## 维护与删除

playback_access 仅证明解析，不是观看记录。维护保护六小时近期访问、用户收藏/观看/进度和手动置顶；Episode 按 SeriesName 保护整部剧，归属或保护读取失败停止。普通播放不永久置顶，也不预热下一集。

selfheal 逐叶检查 live、有路径 done 并校正 done 无路径；鉴权、网络、分页失败为未知。每批缺失最多三十二个，取得片库独占锁并确认空闲后再核验，先恢复入口、再提交 cleaned。云删除失败不报完成，共享目录和未到期其他集保留。

账号配额读取成功时用 85%/70% 水位；点播不足 200 GiB 不淘汰，单轮约 30% 护栏；容量不可得时用点播 2 TiB/1 TiB 兜底。不完整枚举不能驱动淘汰，dry-run 也访问真实服务。独立 cleanup 等调度锁最多 3600 秒，每十五秒重试，超时退出 75 且未执行业务；取得后仍检查片库/会话。--enforce-quota 只处理错配/配额，普通运行另处理到期队列；均不清理 Jellyfin 图片。

图片由宿主日更在本次扫描确认完成后 strict 清理，目录访问/default ACL、引用完整性及回滚见验证流程。回收站按用户要求不处理。
