# Quark-VOD 3.0.1

This maintenance release fixes transfer recovery, retention, and media transport.

- Persist the exact saved file identity before format correction, recover interrupted renames, and atomically commit completed transfers with their expiry work. Unresolved saves remain protected from resets and duplicate submissions.
- Use actual playback access for LRU retention, preserve explicit pins and unfinished progress, protect in-flight saves, and increase bounded directory enumeration capacity.
- Apply the configured OpenList download boundary to Range reads and probes. Serialize token refresh, bound API responses, and reject API redirects that could forward credentials.
- Share bounded stream capacity across clean and media routes; health checks remain responsive when synchronous workers are busy.
- Improve configurable mount, category, image-path, and model compatibility; retain strict identity checks for episode selection and explicit editions.
- Batch complete library registration, remove confirmed stale mappings, expire search caches, and propagate state write failures.

The state database upgrades transactionally to schema 2. Stop all old service and host-side writers and create a verified SQLite online backup before upgrading. Rolling back to an older binary requires a compatible backup; do not erase state to bypass migration.

Image cleanup requires explicit metadata directory/path-prefix configuration and fails closed for unknown references. Existing `--enforce-quota` scope is preserved; add `--with-expiry` to request expiry processing. Orphan cloud objects are not automatically removed.

Assets contain the Python wheel, source distribution, and SHA-256 checksums. This release does not publish to PyPI or a container registry. Synthetic regression and installation checks do not replace deployment-specific validation or actual cloud playback acceptance.

See [maintenance details](https://github.com/gnod-x/quark-vod/blob/v3.0.1/docs/maintenance-fixes-3.0.1.md) for behavior and integration boundaries.
