# Quark-VOD 3.1.0

发行日期：2026-11-25。Python包、CLI、HTTP元数据及默认Docker构建版本均为3.1.0，状态库 schema为3。本发行继承公共3.0.1源码，发行源码只包含独立Quark-VOD内核、公共文档/示例、测试及CI，不包含家庭影院宿主工程、私人配置、运维仓库历史或真实账号凭据。

## 本次变化

- Work身份纳入可选variant；默认历史入口继续兼容，显式版本按hdr/sdr/dubbed/remux隔离。作品、年份、类型、季集和同一枚举路径的身份校验先于画质；标签不等于技术实测。
- 搜索支持html/json/tg_web/pansou及结构化partial诊断、预算与失败保留语义。枚举目标文件后排名；配置缺失、搜索不完整和本次无合格候选分别报告。
- 保存先写可恢复意图；未知提交只恢复原候选，不因超时盲重发。魔数不足或网络失败视为未知；确认非视频后，也要确认精确对象安全删除才允许回退。
- 安全换源使用独立候选行及持久journal，保存就绪、激活全部安全STRM并回读后，再在同一SQLite事务提交done/audit/ban/replacement receipt。失败保旧；提交后旧leaf删除未确认返回cleanup_pending，不撤销新源可播状态。
- 分享枚举账号可使用只读scout池；真正保存重新以主号取token和fid_token。令牌桶只在单Python进程内共享，部署者负责跨进程总预算。
- 同目录字幕有有界队列与未知保存恢复，安全路径和版本核对后才写侧车；下一集预取须精确匹配当前观看源及季集、至少45%进度且未暂停。
- 通知、Jellyfin集成、破坏性维护、自愈、启动扫描/云写探针及AI继续显式启用；空配置可健康启动，不表示搜索、保存或播放依赖已就绪。

完整恢复约束见[转存实现](../transfer-evolution.md)，配置与API见[安装指南](../quickstart.md)及[插件指南](../plugins.md)。

## Schema 3迁移：先停全部writer并备份

3.0.1使用schema 2；更早受支持schema经冻结迁移到schema 3。新版增加variant隔离、任务/通知相关状态及换源receipt。离线迁移回归不能替代操作者对现有数据库的备份与验证。

1. 停止所有访问同一状态库的旧容器、宿主cron、后台任务和其他writer，不能让schema 2与schema 3程序共同写库。
2. 使用SQLite backup API生成独立一致快照（包含已提交WAL内容），对备份执行integrity_check并确认可恢复；不能仅复制在线主.db而漏掉WAL。保留旧镜像、配置和数据挂载关系，凭据备份由操作者在原安全边界内保管。
3. 使用新镜像及原显式配置启动一个writer，核验包/HTTP版本3.1.0、user_version=3、默认variant历史行及实际加载代码；再执行受控搜索、已有保存播放及Jellyfin入口验证，逐步恢复宿主任务。
4. 回退前再次停全部writer并保留新版数据。schema 2代码不能直接打开并继续写已迁移schema 3库；不得手改user_version伪装回退。先明确备份后新增保存/播放等活动的处置，再用经过验证的兼容备份、旧镜像与对应配置恢复，避免旧主库配新WAL。

具体备份命令与回退限制见[升级、备份与回滚](../quickstart.md#升级备份与回滚)。换源journal、未决save intent和receipt是恢复证据，不能作为普通缓存清理。

## 运行与安全边界

- 无Jellyfin模式返回已验证URL，不创建或改写片库。Jellyfin模式要求既有安全非空映射；目录逃逸、符号链接或错误variant均拒绝。
- 保存/删除使用写挂载、播放使用读挂载；只删除确认安全的精确对象，不递归清分享槽位，不碰回收站，不直接写Jellyfin数据库。
- 管理API使用Bearer token，无token禁用管理；播放入口不构成面向公网的用户鉴权系统。默认Compose仅loopback发布、非root、只读根、256MiB/128pids。
- 包内不含Cookie、OpenList/Jellyfin令牌、搜索私有配置或.env。Cookie滚动持久化须由操作者显式配置私有状态文件；未配置只在内存更新。
- 本发行不承诺已有公共容器仓库或PyPI上传；发布文件和镜像由实际发布渠道提供，Compose可从源码构建。源码commit及镜像OCI revision应由构建者记录，不以运维私有commit替代公共core来源。

## 验证与尚未完成的生产验收

本次执行独立进程核心离线全套、包内容/版本检查及3.1.0镜像构建检查。测试使用临时SQLite、文件和模拟I/O；详细计数与SHA256随构建产物记录。3.1.0发布不表示所有真实云环境、设备、自然调度或全片播放均已通过。

2026-11-25历史one隔离搜索的30片样本为30/30 partial、21/30名称代理命中，P95 12.382秒；这不是70%真实有效召回率，也不能证明95%召回达标。后续预算修复的响应时限结果必须连同partial、未执行变体及候选变化解释，不能推定95%召回或片库95%可播率已达到。

真实账号保存、选定历史失败分享、外挂字幕落地、跨内外网OpenList可达性、Jellyfin/客户端多版本与HDR/DV兼容、真实换源和回退、通知接收及自然cron周期仍需由部署者在受控环境分别验收。健康检查、短字节探针、PlaybackInfo、短段解码和全片观看不能相互替代。[开发历史记录](../development-20261125.md)仅说明开发范围与当时边界，其私人运维工作区证据不是公共安装依赖。
