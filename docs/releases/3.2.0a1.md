# 3.2.0a1 — unified cinema and automation candidate

This alpha combines the project-owned cinema code into one installable package.
It is a development candidate, not a claim that any existing host was upgraded.

- The authenticated administration page now includes Cinema and Tasks & Models.
  Cinema retains catalogue search, season/episode/variant selection, exact-file
  inspection, source replacement, subscriptions and task progress.
- Task configuration persists schedules, timezone, enabled flags, runtime
  budgets, AI endpoint, primary/fallback models and stage reasoning levels.
  Defaults disable scheduling, every task and AI.
- A separate scheduler/worker owns a bounded queue and task history, launches
  fixed task modules and reclaims their process groups. Existing save intents,
  checkpoints and library protection remain in the task implementations.
- Optional hometheater job code ships inside the package, with explicit paths,
  package-local imports and configured model routing. A sibling source checkout,
  fixed private IP or vendor model name is not required.
- Jellyfin wrappers ship as source scripts with an export command. Actual
  FFmpeg/ffprobe, jq and curl remain independently installed upstream software.
- Docker Compose provides an optional automation profile; API and worker share
  the same installed version and data directory.

The core SQLite schema remains version 3. Stop old writers and preserve a
verified backup when switching deployments. Remove duplicate old cron entries
before enabling the new scheduler. See the [migration guide](../unified-migration.md).

Fixture tests and installation/container checks do not certify real account
saving, production AI calls, notification delivery, full media decoding or
playback from a user's device. Those checks belong to the target deployment.
