# 3.0.1 维护修复说明

本版本修复点播状态、清理与资源读取问题。数据库升级至 schema 2，新增可空的
save_file_fid，在转存后格式改名前持久化夸克文件身份；完成状态和到期队列原子提交。
旧数据库保留记录并事务迁移。升级前需按架构文档停写并完成在线备份；回滚旧二进制
需恢复与旧 schema 兼容的备份，不能以重置状态库代替升级。

| 审计项 | 最终行为与判断 |
| --- | --- |
| P0-1 配额与到期清理 | 收藏、未完播进度、显式置顶与近 6 小时访问保留；已看历史和自动预热不永久保护。按实际访问 LRU，目录统计预算提高至 10000 并验证输入；保护所有在途引用。无主对象仍不自动删除。 |
| P0-2 保存意图 | 未决意图的管理重置返回 409；重试恢复原任务。没有采用超时后盲目清除/重提，因响应丢失不能证明原写入失败。 |
| P0-3 门户入库 | 宿主适配使用专用 pending 新增入口、共享播放租约与作品/季锁；批量维护继续检查空闲会话。 |
| P0-4 可移植性 | 使用配置的读写挂载、OpenList origin、Season 目录布局；图片清理目录和容器路径映射显式配置；AI reasoning_effort 默认省略。 |
| P0-5 宿主导入 | 宿主脚本不再优先导入旧公共工作树；磁盘权限须以目标运行环境取证，不自动递归改属主。 |
| P1-1 格式扶正 | 嗅探前刷新目录，恢复保存补做扶正；改名前持久化文件 ID，格式不明不标 done。 |
| P1-2 STRM 协议 | 宿主评分和修复共用 live/远端路径解析，兼容稳定 /play、/clean 及旧 /d/。 |
| P1-3 内部流读取 | 清洗、缓存分块、格式嗅探与就绪探针均经安全下载器；起始 URL 为配置的 OpenList /d/，外站重定向校验公网地址并固定连接 IP。 |
| P1-4 门户 | 在线 SQLite 只读并关闭连接；写请求校验同源，移除跨站通配 CORS；GET reload 不再重启。该校验是 CSRF 防护。 |
| P1-5 并发 | /clean 与 /media 共享 32 个流槽位，失败和断连释放资源；/health 不占同步线程池。 |
| P2-1 旧链路 | 移除无生产调用的 CMS 播放函数和未接线的 AI 标题复核模块；身份排名继续使用确定性规则，保留 AI 文件名解析。 |
| P2-2 文件名 | 支持通用压制组后缀及更多明确技术/地区标签，仍拒绝版本、季集、年份与作品冲突。 |
| P2-3 生命周期 | 访问会话统计、规范预热标题、一次提交 STRM 扫描与失效映射清理、批量查询、写错误回滚、安全日志、缓存过期、登录合并与响应上限均完成。OpenList API/上传额外禁止重定向，防凭据转发。 |

清理调度保持兼容：旧 --enforce-quota 不排空到期队列；需要到期清理时必须显式增加
--with-expiry。图片清理由独立作业在完成扫描及路径/权限预检后执行。

测试使用临时 SQLite、合成媒体和 stub；它们不等于用户设备、真实云文件转存或
Jellyfin 解码验收。宿主调度、权限、无主云文件纳管与真实播放须在目标部署另行验证。
